# Claude 娘 · 橘花书房视觉设计

浅色主题采用奶油白、暖橘与焦糖棕；深色主题采用深咖、暖灰与低饱和橘色。书房场景中的左侧是坐姿阅读人物，右侧是持书半身人物。两张面部位于任务内容列外侧，避免正文卡片遮盖。背景图不包含窗口、按钮或文字。

Dream Skin 的原生 UI 覆盖在场景之上。`theme.css` 设置公开部件的颜色、边框和阴影。Dream Skin 的本地扩展为侧栏绘制书页色底、细金线框和顶部橘花饰，为当前会话绘制书签式选中态，并在新聊天入口、项目分组、任务顶栏和输入框外沿绘制细线与小花。图案位于控件边缘，忽略点击，不增加动画、额外文案或任务状态联动。窗口宽度不超过 1000px 时收起场景图，避免人物处在正文下方。

主题 ZIP 包含背景图、`theme.json` 和 `theme.css`。侧栏花饰、输入框角饰和顶部渐变层的样式位于 Dream Skin 的共享渲染层，主题专属规则在 [atelier-theme 分支](https://github.com/X-Immortal/Codex-Dream-Skin/tree/atelier-theme)维护。
